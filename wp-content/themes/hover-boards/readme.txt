== Description ==

Hover Boards is a responsive theme built with structured layouts and flexible customization options for product-centered websites. The design includes homepage banners, product grids, category sections, customizable headers, and organized navigation menus. The theme supports mobile-friendly layouts to maintain usability across different screen sizes and devices. It also includes widget-ready areas, typography settings, color management controls, and customizable footer sections. Hover Boards features SEO-conscious coding practices, optimized page layouts, and compatibility with commonly used plugins. The theme supports image galleries, featured product sections, blog integration, and social media connectivity for content management and presentation. Additional functionality includes translation readiness, browser compatibility, and easy customization through built-in settings. The layout focuses on clean spacing and structured content placement to support organized product display and simplified navigation. Hover Boards also provides flexible section arrangements that can be adjusted according to branding and content requirements.

== Installation ==

1. In your admin panel, go to Appearance > Themes and click the Add New button.
2. Click Upload Theme and Choose File, then select the theme's .zip file. Click Install Now.
3. Click Activate to use your new theme right away.
